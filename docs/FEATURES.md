## 1. 界面总览

自上而下布局：

```
┌──────────────────────────────────────────────────────────────┐
│ 自定义标题栏（图标 · 文件名 · 主题按钮 · 最小化/最大化/关闭）    │
├──────────────────────────────────────────────────────────────┤
│ 标签栏（文件标签… · + 新建）                                    │
├──────────────────────────────────────────────────────────────┤
│ 菜单栏（文件 · 视图）                                          │
├──────────────────────────────────────────────────────────────┤
│ 格式化工具栏（B I S | H1 H2 H3 | 列表 | 代码/引用/链接/表格…）  │
├──────────┬──────────┬───────────────────────────────────────┤
│ 资源管理器 │ 目录(TOC) │  编辑器区域（WYSIWYG / 分屏源码）      │
│ (文件树)  │          │                                       │
├──────────┴──────────┴───────────────────────────────────────┤
│ 状态栏（模式 · UTF-8 · 字数 | 行数 | 字符数）                  │
└──────────────────────────────────────────────────────────────┘
```

- 入口文件：`src/renderer/index.html`（DOM 结构）、`src/renderer/style.css`（样式）、`src/renderer/renderer.js`（逻辑）
- 应用启动自动创建一个"未命名"标签并载入示例文档（`# 欢迎使用 MD Tool ✨`）

## 2. 文件操作

### 2.1 新建文件

- 入口：菜单「文件 → 新建文件」、标签栏 `+` 按钮、快捷键 `Ctrl+N`
- 行为：创建一个无路径的"未命名"标签并激活
- 实现：`newFile()` → `TabManager.createTab(null, '')` + `activateTab()`

### 2.2 打开文件

- 入口：菜单「文件 → 打开文件」、快捷键 `Ctrl+O`
- 行为：弹出系统原生对话框（过滤 `.md` / `.markdown`），选择后读取内容并打开；**若该文件已在某标签中打开，则直接激活已有标签，不重复创建**
- 实现：Rust `open_file` 命令 + `TabManager.findTabByPath()` 去重
- 细节：打开成功后，文件所在目录会被记录进 Rust 端路径白名单（之后保存才被允许）

### 2.3 保存

- 入口：菜单「文件 → 保存」、快捷键 `Ctrl+S`
- 行为：
  - 当前文件已有路径 → 直接覆写原文件（不弹对话框）
  - 当前文件无路径（未命名）→ 弹出另存为对话框
- 成功后：移除标题栏与标签的修改标记（`●`），Toast 提示"文件已保存"
- 实现：`saveFile()` → `invoke('save_file', {filePath, content})` 或 `invoke('save_file_dialog', {content})`

### 2.4 另存为

- 入口：菜单「文件 → 另存为」、快捷键 `Ctrl+Shift+S`
- 行为：始终弹出另存为对话框，写入后**更新当前标签的文件路径与标题**，清除修改标记
- 实现：`invoke('save_file_dialog', {content})` + `updateFilePath()`

### 2.5 导出 HTML

- 入口：菜单「文件 → 导出 HTML」
- 行为：将当前编辑区渲染的 HTML（经 DOMPurify 二次消毒，禁 script/iframe/object/embed/form）包装为带内联样式的完整 HTML 文档，弹出保存对话框（.html）写出
- 实现：`renderer.js` 菜单处理函数（构造完整 HTML 模板）+ Rust `export_html` 命令
- 注意：导出内容为**当前渲染结果**，不包含 hljs 高亮样式表，但包含基础排版样式（正文、代码块、表格、引用块等）

### 2.6 未保存修改标记

- 编辑内容变化时：标题栏文件名加 `modified` 样式（下划线/高亮），标签标题前显示 `●`
- 保存成功后标记消失
- 关闭有修改的标签时弹出确认（`confirm`）：确定关闭将丢失更改

## 3. 多标签页管理

**核心**：`TabManager`（`renderer.js` 顶部），标签状态保存在 `tabs[]` 数组，每项为 `{ id, filePath, markdownContent, isModified, scrollTop }`。

### 3.1 功能清单

| 功能 | 操作 | 说明 |
|------|------|------|
| 新建标签 | 标签栏 `+` 或 `Ctrl+N` | 创建"未命名"空白标签 |
| 切换标签 | 点击标签 | 自动保存当前编辑内容到原标签，加载目标标签内容，标题栏路径跟随更新 |
| 关闭标签 | 点击标签上的 `×` | 有未保存修改时先弹确认框 |
| 拖拽排序 | 按住标签左右拖动 | mouse 事件实现，见 3.2 |
| 去重打开 | 打开已在标签中的文件 | 直接激活已有标签 |

### 3.2 拖拽排序（mouse 事件实现）

- 触发阈值：按住标签移动超过 **5px** 才进入拖拽状态（防误触）
- 拖拽中：原标签半透明（`dragging` 类）、生成**幽灵元素**跟随鼠标（`#tab-ghost`，缩放 1.05 + 阴影）、目标位置显示**插入指示线**（`insert-before` / `insert-after` 类，3px 高亮竖线）
- 释放：根据鼠标 X 坐标与各标签中线判断插入点，重排 `TabManager.tabs` 数组并调用 `_reorderTabDOMs()` 重渲染，恢复 active 状态
- 点击关闭按钮（`×`）不触发拖拽；拖拽结束自动清理所有拖拽状态
- 实现位置：`renderer.js` 末尾自执行 IIFE（`mousedown` / `mousemove` / `mouseup` 三个全局监听）

### 3.3 状态保持

- 每个标签独立保存 `markdownContent` 与分屏模式下的 `scrollTop`
- 切换标签时先通过 `getCurrentMarkdown()` 收集当前编辑内容再切换，不丢失任何未保存输入

## 4. WYSIWYG 所见即所得编辑

Typora 风格：**平时看到渲染后的富文本，点击段落进入 Markdown 源码编辑态**。

### 4.1 段落模型

- 文档按**双换行**（空行）分割为逻辑段落（`splitParagraphs()`）
- **代码围栏（```）内的空行不会被分割**（识别 ```` ``` ```` 行切换 inCodeBlock 状态）
- 每段渲染为 `<div class="wysiwyg-block" data-source="原始Markdown" data-index="序号">`

### 4.2 编辑流程

1. **点击段落** → 该块替换为 `<textarea class="wysiwyg-edit">`，内容为原始 Markdown，自动聚焦，高度按 `scrollHeight` 自适应；状态栏显示"编辑模式"
2. **输入** → textarea 高度实时自适应；**Tab 键插入 2 个空格**（不跳焦点）
3. **失焦（blur）** → 取回内容更新对应段落，重新渲染为 HTML，恢复"预览模式"；TOC、代码高亮、状态栏同步刷新

### 4.3 内容收集

- `getCurrentMarkdown()`：若某段正处于编辑态，用 textarea 当前值替换该段，其余段用 `data-source`，按 `\n\n` 拼接，保证保存/切换标签不丢失正在编辑的内容

### 4.4 交互细节

- 编辑态 textarea 背景色区别于普通段落（亮色主题淡黄 / 深色主题高亮），focus 时 accent 色边框光晕
- 段落块 hover 显示浅色边框提示可点击

## 5. 分屏模式

- **入口**：工具栏右侧「⊟ 分屏」按钮、菜单「视图 → 切换分屏模式」
- **行为**：
  - 开启：右侧显示"Markdown 源码"面板（`#raw-editor`，textarea），载入当前文档源码；此后**在源码区输入，WYSIWYG 区同步渲染**（200ms debounce 防抖）
  - 关闭：以源码区当前内容重新渲染 WYSIWYG 区，移除监听
- 状态栏显示"分屏模式"
- 实现：`toggleSplitMode()` + `onRawInput()`（`_rawSyncTimer` 200ms 防抖），同步时自动标记未保存
- 注意：分屏模式下点击段落**不会**进入编辑态（`onBlockClick` 首行即 `if (isSplitMode) return`）；此时内容读取走源码 textarea

## 6. Markdown 渲染与代码高亮

### 6.1 渲染管线

```
Markdown 源码 → splitParagraphs 分段 → marked.parse（gfm + breaks）
            → DOMPurify.sanitize（白名单） → .wysiwyg-block innerHTML
```

- **marked 配置**：`gfm: true`（GFM 表格/任务列表/删除线）、`breaks: true`（单换行即换行）、highlight 回调
- **DOMPurify 消毒**（`renderMarkdown()`）：
  - 允许额外：`iframe` 标签与 `allow/allowfullscreen/frameborder/scrolling` 属性
  - 禁止：`style`/`form`/`input`/`textarea`/`button` 标签，`onerror`/`onload`/`onclick`/`onmouseover` 事件属性

### 6.2 支持的语法（marked GFM）

标题（H1–H6）、粗体/斜体/删除线、有序/无序/任务列表、行内代码/代码块（带围栏语言标注）、引用块、链接、图片、表格、水平分割线、HTML 片段（经消毒）。

### 6.3 代码高亮

- 引擎：highlight.js（`hljs.bundle.js`，IIFE 打包，**离线可用**）
- 内置语言（21 种，`scripts/build-hljs.js` 中 `languages` 数组）：

  ```
  javascript, typescript, python, java, cpp, c, csharp, go, rust, swift,
  kotlin, ruby, php, bash, sql, xml, css, json, yaml, markdown, diff
  ```

- 规则：代码块标注了支持的语言 → `hljs.highlight(code, {language})`；未知语言 → `hljs.highlightAuto()` 自动识别
- 视觉：代码块右上角显示语言标签（`data-lang`），深色/浅色两套高亮配色内联在 `style.css`
- **一键复制**：代码块悬浮“复制”按钮（hover 显示），点击复制整块代码到剪贴板（`navigator.clipboard`，失败自动回退 `execCommand`），成功后按钮短暂显示“已复制”
- 新增语言：修改 `scripts/build-hljs.js` 的 `languages` 数组 → 运行 `node scripts/build-hljs.js` 重新生成

## 7. 自动目录（TOC）

- 面板：主内容区左侧「目录」面板（`#toc-panel`）
- 生成时机：每次 `renderAll()` / 段落失焦 / 分屏同步后调用 `buildToc()`
- **层级结构**：扫描 WYSIWYG 区 `h1–h6`，用层级栈生成**嵌套 `<ul>/<li>`**，子级缩进
- **锚点**：每个 heading 按规则生成 `id`（见项目文档 §9.4），目录链接 `href="#{id}"` 与之完全一致；中文标题保留中文字符
- **点击跳转**：点击目录项平滑滚动（`scrollIntoView`）到对应标题，目标标题短暂闪烁高亮（`.flash-highlight`）
- **滚动跟踪（scroll-spy）**：编辑区滚动时（80ms 节流）自动把当前阅读位置的标题在 TOC 中高亮（`.active`），随时可知“我在文档哪一节”
- 空文档显示"暂无标题"占位
- 面板可隐藏：菜单「视图 → 切换目录面板」或专注模式自动隐藏

## 8. 文件树工作区

- 面板：主内容区最左侧「资源管理器」（`#file-tree-panel`）
- **打开文件夹**：菜单「文件 → 打开文件夹」、文件树空态的“打开文件夹…”按钮 → 系统对话框选择文件夹 → Rust `open_folder` 记录白名单 → `get_folder_tree` 递归获取目录树（**最大 10 层**）→ 渲染
- **面板收放**：菜单「视图 → 切换资源管理器」可折叠/展开资源管理器面板（平滑宽度过渡）
- **节点交互**：
  - 文件夹：`▶` 箭头，点击展开/折叠（箭头旋转 90°，子列表 `file-tree-collapsed` 类控制显隐）
  - 文件：点击 → `read_file_text` 读取内容 → 新建标签打开（已在标签中则激活）
- **不过滤文件类型**：所有文件均可点击；二进制/非 UTF-8 文件读取失败时 Toast 提示"打开文件失败"
- 实现：`FileTree` 命名空间（`load` / `render` / `toggleFolder` / `openFile`），单元测试见 `__tests__/fileTree.test.js`

## 9. 格式化工具栏

位于菜单栏下方。**先点击一个段落进入编辑态，再使用工具栏**；未进入编辑态时点击会 Toast 提示"请先点击一个段落进行编辑"。

| 分组 | 按钮 | 行为 | 实现 |
|------|------|------|------|
| 文字 | `B` 粗体 | 选中文本包裹 `**` | `insertFormat('**','**')` |
| 文字 | `I` 斜体 | 选中文本包裹 `*` | `insertFormat('*','*')` |
| 文字 | `S` 删除线 | 选中文本包裹 `~~` | `insertFormat('~~','~~')` |
| 标题 | H1 / H2 / H3 | 行首插入 `# `/`## `/`### ` | `insertLine()` |
| 列表 | `≡` 无序列表 | 行首插入 `- ` | `insertLine('- ')` |
| 列表 | `①` 有序列表 | 行首插入 `1. ` | `insertLine('1. ')` |
| 列表 | `☑` 任务列表 | 行首插入 `- [ ] ` | `insertLine('- [ ] ')` |
| 插入 | `` ` `` 行内代码 | 选中文本包裹 `` ` `` | `insertFormat` |
| 插入 | `⌥` 代码块 | 插入 ` ```\n…\n``` ` | `insertFormat('```\n','\n```')` |
| 插入 | `❝` 引用块 | 行首插入 `> ` | `insertLine('> ')` |
| 插入 | `🔗` 链接 | 插入 `[选中](url)` | `insertFormat('[','](url)')` |
| 插入 | `⊞` 表格 | 光标处插入 3 列示例表格 | 专用处理函数 |
| 插入 | `─` 分割线 | 光标处插入 `---` | 专用处理函数 |

- `insertFormat(before, after)`：包裹选中文本并保持选中状态；`insertLine(prefix)`：在光标所在行首插入前缀
- 操作后自动触发 `input` 事件以同步高度、状态栏与（分屏模式下）渲染

## 12. 主题切换

- **入口**：标题栏 `🌙` / `☀️` 按钮
- **主题**：深色（默认，`localStorage` 无记录时取 `'dark'`）/ 亮色两套
- **持久化**：`localStorage` 键名 `theme`（`'dark'` / `'light'`），启动时读取
- **实现机制**：
  - `document.body.dataset.theme` 切换 CSS 变量体系（`style.css` 中 `:root` 亮色 + `[data-theme="dark"]` 深色两套变量）
  - **代码高亮配色随主题切换**：hljs 颜色内联在 style.css 两套主题下（无外部 CSS 加载延迟）
  - 过渡动画仅作用于 `background-color/border-color/color/opacity`，切换流畅
- 按钮图标：深色主题下显示 `☀️`（点击切亮色），亮色主题下显示 `🌙`

## 13. 专注模式

- **入口**：菜单「视图 → 专注模式」或 `F11`
- **行为**：
  - 进入：隐藏 TOC 面板，`body` 加 `focus-mode` 类（通常加宽编辑区、弱化干扰元素），Toast 提示"已进入专注模式（按 F11 退出）"
  - 退出：恢复 TOC 面板，Toast 提示"已退出专注模式"
- **`Esc`** 也可退出专注模式（并同时关闭展开的下拉菜单）
- 实现：`toggleFocusMode()`

## 14. 自定义标题栏与窗口控制

- **无边框窗口**：`tauri.conf.json` 中 `decorations: false`
- **拖拽移动**：标题栏元素带 `data-tauri-drag-region` 属性（Tauri 原生支持，等价旧版 `-webkit-app-region: drag`）
- **窗口控制按钮**（`data-tauri-no-drag` 区域，点击不受拖拽影响）：
  - `─` 最小化：`getCurrentWindow().minimize()`
  - `□` / `❐` 最大化/还原：`toggleMaximize()`，图标随 `isMaximized()` 状态切换（`updateMaximizeBtn()`）
  - `✕` 关闭：`getCurrentWindow().close()`
- **文件路径显示**：仅显示**文件名**（隐私考虑，不显示完整路径），带未保存修改时加高亮样式；`document.title` 同步为 `文件名 — MD Tool`
- 标题栏左侧：应用图标（内嵌 SVG）+ 文件名；右侧：主题按钮 + 窗口控制

## 15. Toast 通知系统

- 容器：`#toast-container`（右下角）
- 类型：`success`（绿色）/ `error`（红色）/ `info`（默认）
- 结构：图标 + 消息文本 + 底部进度条（渐变，随主题切换）
- 行为：3 秒后自动淡出移除（`toast-out` 动画）；**消息用 `textContent` 渲染，杜绝 XSS**
- 接口：`showToast(message, type = 'info', duration = 3000)`

典型使用场景：文件已保存 ✅ / 保存失败 ❌ / 已新建文件 ℹ / 文件已打开 ✅ / HTML 导出成功 ✅ / 加载文件夹失败 ❌ / 进入/退出专注模式 ℹ。

## 16. 快捷键汇总

| 快捷键 | 功能 |
|--------|------|

| `Ctrl+O` | 打开文件 |
